# Research

One folder per theme/episode. Add deep-dive briefs here as markdown files.

Contents
--------

- Episodes: folders `Ep1/` `Ep2/` `Ep3/` `Ep4/` contain episode-specific research briefs and commission notes.
- `All Research PDFs/` contains consolidated briefs and reference extracts.
- `research_htmls/` contains exported HTML versions of episode briefs.

Quick links
-----------

- Episode themes & conflicts summary: `Episodes_Themes_and_Conflicts.md` (new)
- Research brief template: `Research_Brief_Template.md`

How to use this folder
----------------------

1. Read the episode brief (e.g. `Ep1/Ep1_Research_Brief.md`) for narrative hooks, sources, and suggested quotes.
2. Consult the commission notes (e.g. `Ep2/02_Research_Commissions.md`) for scope and additional culture-specific detail.
3. Use `Episodes_Themes_and_Conflicts.md` for a quick overview of each episode's main themes and the central conflicts or tensions to highlight in scripts.

If you update or add briefs, please link them from this README so others can find them quickly.
